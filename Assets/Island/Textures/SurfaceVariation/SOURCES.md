# Island surface variation textures

Downloaded 2026-09-29 from Poly Haven's public asset downloads. All four assets
are CC0: https://polyhaven.com/license (commercial use and redistribution allowed).
Original 2K JPG diffuse and OpenGL normal maps are preserved without pixel edits.

- Fine sand: https://polyhaven.com/a/sand_02
- Damp beach sand: https://polyhaven.com/a/damp_beach_sand
- Grass ground: https://polyhaven.com/a/grass_ground
- Withered grass: https://polyhaven.com/a/withered_grass

Downloaded files were checked against the MD5 checksums in the source API metadata.
Unity imports use mipmaps, repeat wrapping, 2K maximum resolution and compressed
textures. Normal maps are imported as NormalMap (not color/sRGB textures).
