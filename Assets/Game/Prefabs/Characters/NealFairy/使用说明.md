# Neal 仙女 prefab

将同文件夹中的 `Neal Fairy.prefab` 拖入场景。模型使用原素材中的纹理和翅膀材质，初始高度约 1.1 米。

展开 `Neal Fairy Model/Hips` 可以找到身体骨架：脊柱、胸部、脖子、头、左右上臂、前臂、手、大腿、小腿和脚。`Chest` 下的 `Wing.L` 和 `Wing.R` 分别控制两侧翅膀，可以在 Animation 窗口给这些 Transform 的旋转添加关键帧。

这是根据静态原模型建立的 Unity Generic 骨架，不是 Humanoid T 姿势骨架；原素材没有动画和手指骨骼。身体蒙皮是初步自动绑定，适合开始制作轻幅度动作；制作大幅度动作时可能需要进一步调整权重。翅膀是左右两侧分别刚性旋转的结构。
