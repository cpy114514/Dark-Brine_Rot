# Sahur swing sounds

Original air and movement layers for Sahur. swish-1, swish-5 and swish-9
follow the light combo stages. swish-12 is the charged swing. The filenames
carry the existing animation cue assignments. The source is
Tools/GenerateGameplayAudio.py.

Combo animations come from Quaternius's [Universal Animation Library 2](https://quaternius.com/packs/universalanimationlibrary2.html)
(CC0), imported at Animations/Gameplay/QuaterniusUAL2/UAL2_Standard.fbx.
