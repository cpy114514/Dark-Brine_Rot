# Sahur swing sounds

The four `swish-*.wav` files in this folder are selected from **Swishes Sound Pack** by artisticdude:
https://opengameart.org/content/swishes-sound-pack

Source download: https://opengameart.org/sites/default/files/swishes.zip
License: CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/)

`swish-1`, `swish-5`, and `swish-9` are used for Sahur's three light combo stages; `swish-12` is used for the charged attack. The unselected files from the source pack are not included in this project.

Combo animations come from Quaternius's **Universal Animation Library 2** (also CC0), already imported at `Animations/Gameplay/QuaterniusUAL2/UAL2_Standard.fbx`:
https://quaternius.com/packs/universalanimationlibrary2.html
