# KayKit Skeleton Warrior animation source

Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0

Author: Kay Lousberg (KayKit). Licensed CC0 1.0 Universal; see the source repository's LICENSE.txt.

The small Humanoid clips in this folder are extracted from the source pack's `Skeleton_Warrior.fbx`:

- `SahurJumpSlash.anim`: `1H_Melee_Attack_Jump_Chop`
- `SahurStickCombo1.anim`: `1H_Melee_Attack_Slice_Horizontal`
- `SahurStickCombo2.anim`: `1H_Melee_Attack_Slice_Diagonal`
- `SahurStickCombo3.anim`: `1H_Melee_Attack_Chop`

Only these clips are kept in the project to avoid adding the 22 MB source character model to version control. To recreate one, download the source FBX to this folder and run **Mavis > Sahur > Setup Jump Slash** or **Setup Stick Three-Hit Combo**.
