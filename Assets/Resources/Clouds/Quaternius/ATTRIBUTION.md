# Quaternius Cloud Mesh

`Cloud1.fbx` is from the Quaternius Modular Platformer Pack, downloaded on 2026-09-15 from:

- https://quaternius.com/packs/modularplatformer.html
- https://drive.google.com/drive/folders/1ku_XmbHOZ5ypgKCAjpzX6hlXaOJT7Uoq

The source declares the pack to be CC0 / public domain. The mesh is used here as the source geometry for the runtime Celestial Cloudscape entities, with the project's own cloud material applied at runtime.
