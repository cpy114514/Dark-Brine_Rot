# Dark Brine_Rot

A third-person action game with Tung Tung Tung Sahur as main character.

## Click here to play

https://cpy111.itch.io/dark-brine-rot

## controls

| Action | Input |
| --- | --- |
| Move / look | WASD / mouse |
| Sprint / jump / dodge | Left Shift / Space / Left Ctrl |
| Light attack / three-hit combo | Left mouse button; kept clicking to attack as a combo |
| Charged attack | Hold right mouse button, then release |
| Throw the stick | E |
| Lock on | Middle mouse button |
| Heal | H |
| Equipment | I; use the mouse to browse, equip and close |
| switching wepons/ numbers |
| Activate equipped weakness glasses | G |
| Map | m |
| pause| esc |
