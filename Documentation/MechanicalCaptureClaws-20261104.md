# 鳄鱼飞机机械抓臂修正

## 实际修改

- `BombardinoCaptureClaws` 改为两套石墨色金属机械抓臂：机腹安装法兰与紧固件、肩肘销轴、刚性臂段、连续液压筒/活塞杆，以及三指分节夹爪和深色接触垫。没有动物皮肤、角质尖爪或发光贴图。
- 创建时对现有飞机的可读网格做两次下方射线/三角形求交，安装中心埋入真实机腹约 7cm。当前两个模型局部挂点为 (-0.84,-0.25,0)、(0.84,-0.25,0)，抓取中心约 (0,-1.84,0)。不再使用飞机包围盒最低点作为手部抓点。
- 整个抓臂网格归属飞机可视模型，随其俯仰、侧倾与跨场景飞行。抓点下移，为机械臂和头部留出空间；Sahur 的双手与夹爪继续由同一抓点驱动。保留原有渐进闭合和释放张开时序。
- 独占动态网格 5112 顶点、4 个材质；只在这段演出存在，结束/中断释放专属网格及材质。没有新增伤害碰撞或改变飞机关卡进度。
