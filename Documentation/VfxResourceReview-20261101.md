## Manual Asset Store download

For the two Mirza Beig packs above: open the exact product link, sign in with the Unity account that will own the entitlement, select **Add to My Assets**, accept the displayed terms, then use Unity **Window → Package Manager → My Assets → Download**. Import selectively into an isolated branch/backup first. Unity 6 shader/runtime validation is still required. These packages have **not** been downloaded by task050.

## Local evidence and notices

Downloaded source files, source preview frames, original SHA256 values and the six-way map license discrepancy are recorded under `.codex/vfx050/downloads`. Imported source notices are kept beside the imported files under `Assets/ThirdParty`. Preserve the relevant notices in a shipped build's third-party notices as well. [Unity Companion License](https://unity.com/legal/licenses/unity-companion-license) permits no-charge use connected with valid Unity authoring/distribution; [Unity Package Distribution License](https://unity.com/legal/licenses/unity-package-distribution-license) limits redistribution to integration with project content. These maps are not an engine-independent CC0 asset pack in this project.

No paywalled pack, noncommercial-only source, ripped game asset, or unknown-license shader was imported.
