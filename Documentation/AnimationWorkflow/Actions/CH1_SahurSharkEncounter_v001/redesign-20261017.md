## 01 黑影逼近、跃起砸船

已确定：先看到水下黑影靠近，让 Sahur 发现危险、试图应对却来不及。鲨鱼从水中跃起，狠狠砸碎船；Sahur 没能逃开，被船体冲击掀飞，落到较大残骸上。

建议分镜：
- 黑影从船侧后方逼近，Sahur 注意到水流、低头发现危险，握棍戒备。
- 黑影短暂潜深；Sahur 寻找时，鲨鱼从近处破水跃起，以身体重量压向船身。
- 接触处甲板先塌陷，船体折断、另一侧翘起，脚下支撑的运动将 Sahur 掀飞。
- Sahur 落在大块残骸上，侧身着地、翻滚滑动，用空手撑住板面，再起身。

动作优先级：鲨鱼身体接触 → 船体受力与断裂 → Sahur 失去支撑；不能让人物无接触自行飞出。残骸承重后的倾斜与回浮需要可见。

已确定的开场变速：鲨鱼跃到最高处时短暂放慢，让玩家看清它压在船上方的巨大身影。用户明确选择这一表现。
镜头建议：斜俯远景建立黑影与小船 → Sahur 察觉危险的近景 → 低机位拍鲨鱼破水跃起 → 高点短暂慢动作展示鲨鱼与船的体型关系 → 船侧全景看清下压、断船和掀飞 → 跟随 Sahur 落上残骸。建议开始下压时恢复正常速度，保留砸船的冲击；恢复时点、慢动作长度/倍率及具体机位尚未逐项确认。慢动作不是静止定格，应保留身体、水滴及 Sahur 的连续反应。

## 02 基础操作教程

已确定：教移动、攻击、闪避、蓄力、跳跃和游泳。鲨鱼配合制造教学情境；关键时刻暂停游戏，提示操作，玩家完成要求后继续。用户接受以玩家跳水和游泳教学衔接自动追逐。

建议顺序：残骸上移动/跳跃 → 普通攻击 → 闪避 → 蓄力 → 逃生跳水 → 游泳。跳跃具体是否先单独练习或只在逃生时教，尚待确定。

- 攻击：鲨鱼头部进入可打范围，暂停提示；正确输入衔接恢复后的挥棒和受击退开。
- 闪避：扑咬方向已清楚、仍有躲避时间时暂停；操作后鲨鱼扑空。
- 蓄力：利用露出的破绽，分步引导按住和释放，显示比普通攻击更重的结果。
- 不重复索要已经收到的正确输入；暂停输入处理、蓄力阶段推进规则需在实现前明确。
- 精确键位、教学完成判定、失败重试、跳过方式、启动/有效/恢复窗口未定。

教程成功与伤害规则已确定：正确输入保证对应教学动作成功；鲨鱼攻击仍造成真实扣血，但教程期间的累计伤害不能打死玩家。用户原话：“正确输入就保证对应动作成功，但是鲨鱼还是会造成扣血，但是保证玩家不会死掉，比如说鲨鱼的攻击总伤害是打不死玩家的”。此规则仅确定教程范围，不自动修改后续普通战斗的伤害规则。

设计建议：每个教学步骤只在正确输入后推进，接续到安排好的成功动作；成功闪避的扑咬不得扣血，扣血必须来自画面中真实发生的受击，不能为表现危险强行将成功闪避判成命中。教程内设置累计伤害预算，以实际进入教程时的生命值为依据，确保结余为正；具体预算、最低保留生命、低血量入场处理和重复受击规则待定。暂停等待期间不结算新的攻击伤害。不将“防止死亡”实现为界面扣血后暗中恢复，也不以无限重复攻击绕过累计预算。

已确定的跳水原因：残骸即将被毁，Sahur 被迫跳水，不是主动追击。
建议衔接：蓄力击退鲨鱼后，鲨鱼潜到残骸下方，板面拱起裂开；暂停引导跳水。玩家离板后残骸被撞碎，随后进行短暂游泳教学。教学完成后镜头平顺接管，进入追逐。

## 03 狼狈求生：三次扑咬

已确定：Sahur 每次都差一点被咬到，表现慌乱求生。以下为逐次讨论形成的追逐分镜。

第一口（建议衔接）：鲨鱼从身后跃起扑咬；Sahur 回头才看见，慌忙扎水，嘴在脚后合上。落水冲击将他卷偏，破坏游泳节奏。

第一口镜头已确定：紧贴 Sahur，直到他回头时才和他一起发现鲨鱼已经扑来，不提前切到后方追近的鲨鱼。建议以接近水面的侧前方近景跟随其游泳，限制后方视野；随回头动作切向肩后视角，揭示已经破水扑来的鲨鱼，再用侧面镜头看清下潜、收腿与咬空。具体机位、切点和景别仍为建议。

第二口（用户选择从侧面突然扑来）：Sahur 刚浮出喘气，注意力仍在身后；鲨鱼从侧面破水。他缩头扭身、慌乱划水，鲨鱼贴近肩侧咬空，浪再将他掀翻。重新浮起后，他看到木板并游过去。

第三口（用户选择正在爬板时被咬）：Sahur 胸口刚撑上板面，下半身还在水里；鲨鱼从后面追到。他拼命收腿、拖身上板，双脚刚离水，鲨鱼在板边咬空，Sahur 翻进板内。保留此板供后续交手。

第三口镜头已确定：留在板面高度，从正面拍 Sahur 拼命爬上来，同时看到身后的鲨鱼逼近。构图需保留其肩侧的背景空间，让观众能读出鲨鱼不断缩短的距离，避免 Sahur 完全遮住来袭方向。建议将抓板、撑起胸口和鲨鱼逼近保留在同一镜头中，最后收腿/咬空是否补侧面镜头尚待确定。

已确定的武器连续性：跳水前将棒子收在背后；游泳、双手攀板和翻入板内时仍携带在背后；上板喘息时伸手取下，准备迎击。用户对这一完整建议回复“可以”。收棒与取棒需要可见的动作衔接，不能凭空消失或穿过身体；具体背部固定方式待定。

## 04 喘息、双手下砸

已确定：上板后留一小口喘息时间，在这一段从背后取下棒子，再握紧迎击。双手举过头顶，狠狠向下砸中鲨鱼头部。

建议动作：Sahur 趴着咳水、喘息，发现鲨鱼转回，收腿站起、压低重心。鲨鱼抬头破水时，他以腿、髋、躯干和双臂带动过顶下砸。命中让鲨鱼头部向下偏转，落回水里；Sahur 顺着余势前倾、屈膝，稳住木板后收棒。

接触要求：棍与头先接触再发生反应，不能靠鲨鱼瞬移制造命中。Sahur 的大动作必须具有脚下支撑和余势。

已确定的反击变速：双手下砸命中瞬间短暂放慢，强调打击。用户明确选择这一表现。建议举棒与向下加速保持正常速度，在真实接触时进入短暂慢动作，展示鲨鱼头部受力偏转、Sahur 躯干及双臂继续传力的过程，随后恢复正常速度让鲨鱼落水。慢动作不代替实际接触，也不将姿势冻结。侧面中远景同时呈现 Sahur 全身、板面支撑与鲨鱼的方案仍为建议；倍率、时长及恢复时点尚未确定。

## 05 消失、背后偷袭、扑倒避开

已确定：鲨鱼中棒后潜下，短暂消失；Sahur 紧张寻找。背后水声突然变大，他才发现方向错了，转身时鲨鱼已破水扑来。他直接扑倒，让鲨鱼从背上方掠过。

建议动作：Sahur 起初盯着落水处，之后谨慎寻找。鲨鱼从后方来袭，他无法及时架棒，压低棒子扑向板面。鲨鱼越过他和木板，落入另一侧水中。
背后偷袭的揭示方式已确定：也瞒着观众，等 Sahur 转身时才揭示鲨鱼，不提前展示背后黑影。建议镜头先跟随他搜索错误方向；背后水声骤然变大，他急忙转身时，沿动作切向已经破水扑来的鲨鱼，再以侧面镜头看清扑倒和鲨鱼从背上方掠过。具体机位和切点尚未确定。
动作验证重点：嘴、腹部与背部的危险间距，以及鲨鱼越板过程，不用实际穿模替代险险避开。

## 06 起身投棒、头侧命中、鲨鱼发怒

已确定：Sahur 先站起来，转身大幅抡棒，再用力投出。棒子像回旋镖一样命中露出水面的鲨鱼头侧，之后返回并接回。鲨鱼甩头，彻底生气。

建议动作：空手支撑起身，收腿站稳；棒子拉向身后，转髋、转肩带动大幅投掷。棒子旋转命中头侧，鲨鱼头偏转、游动被打断；Sahur 接棒时顺力收臂。鲨鱼用力甩头，再突然停下转向 Sahur。
投掷旋转方向、弧线、接棒手与鲨鱼甩头次数：制作前待定；当前文字中的幅度与次数不是锁定参数。

投棒去程镜头已确定：镜头跟着旋转的棒子飞向鲨鱼。建议先拍清 Sahur 起身、转体和投出，释放后切到棒子侧后方沿飞行路径跟随，让棒子自身旋转而镜头保持稳定的海平线；前方露出水面的鲨鱼头侧逐渐接近，连续读出命中。跟随速度、距离和命中切点待定。

命中后的镜头顺序已确定：棒子命中头侧后切回 Sahur，拍他接棒，再切到鲨鱼甩头发怒。回程不继续采用跟棒飞行的镜头。建议给回程保留合理时间，让棒子从与前镜运动方向一致的画外位置飞入，Sahur 接住后顺力收臂；随后切到鲨鱼头部与部分躯干，拍清甩头、停止、转向 Sahur 的情绪变化。具体景别、接棒姿势和切点仍待定。

## 07 假扑咬、蓄力尾扫、慢动作打飞

已确定：Sahur 以为鲨鱼又要扑咬，准备再次迎头下砸，结果被突然扫来的尾巴击中。给被打飞的 Sahur 做慢动作特写；下坠时恢复正常速度，猛烈落水。

最终攻击的镜头揭示已确定：镜头也让观众以为鲨鱼要扑咬，直到尾巴扫出才揭示真正的攻击，不提前用尾部蓄力特写提示。建议先以鲨鱼头部/前身的逼近和抬头构图建立扑咬预期，再切 Sahur 举棒迎击，尾巴扫出时才切到能看清转体、尾部轨迹与接触的侧面角度。鲨鱼的身体弯曲和蓄力仍需真实连续地发生，可处在画外或被前身遮挡，不能靠切镜跳过必要动作或瞬移尾巴。

建议动作结构：
1. 蓄力：鲨鱼身体弯曲蓄势，以朝向和头部抬起制造扑咬假象；需要让尾部蓄力在空间上成立。
2. 承诺：Sahur 双手举棍，重心投入迎头下砸，来不及改成格挡。
3. 加速：鲨鱼转体，以脊柱、尾根到尾尖的先后运动完成横向甩尾。
4. 接触：尾击以正常速度命中，Sahur 先从接触部位承受冲量，随后失去板面支撑。
5. 余势：双脚离板进入短暂慢动作特写，展示躯干、肩头、手臂的滞后，惊愕表情和握棒手逐渐松开；棒子脱手旋转。
6. 下坠：上升势头耗尽后，镜头拉到能看清海面的位置，恢复正常速度，身体猛烈落水。

具体尾击部位、飞行方向/距离/高度、慢动作倍率和长度、镜头轨道与景别：未定。
用户新增慢动作特写需求可能要求调整历史固定镜头距离规则；仅记录新需求，尚未改动镜头实现，精确方案待定。

## 08 昏迷、仰面漂流

已确定，用户原话：“直接失去意识，慢慢浮成仰面漂流的姿势”。

落水后不添加挣扎或伸手抓棒的表演。建议先由水花遮住身体，身体短暂没入水下，再缓慢上浮、随浮力转成仰面，手臂放松，头脸保持可见，进入漂流。
棒子落水位置、后续漂流关系，以及本版如何衔接既有上岸剧情，尚待明确；不自行删除或重写既有后续剧情。

## 镜头方向

已确定：用户选择“偏电影动作戏，在扑咬、反击等关键时刻切换机位”。自动动画段采用电影式剪辑，不以全程连续跟拍为目标；各次切镜的景别、方位与时机仍待逐段设计。

设计建议：扑咬前建立来袭方向与逃生空间，再切到能看清险险避开的角度；反击保留蓄力、接触和余势的可读性，不用切镜掩盖接触。相邻镜头保持明确的运动方向和双方位置关系。玩家教程段的操作镜头与自动段分开确定，不能把自动段的切镜选择直接当成改变玩家操作镜头的授权。

最后尾击仍保留已确定的节奏：正常速度命中 → 离板后慢动作特写 → 下坠恢复正常速度并猛烈落水。新电影式剪辑与历史固定距离镜头的具体关系需在新镜头方案中明确，尚未修改实现。
