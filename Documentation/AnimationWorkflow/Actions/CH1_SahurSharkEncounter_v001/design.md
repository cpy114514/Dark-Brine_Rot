## 动作意图

这是一场能看清攻防因果的海上交手。Sahur 用单手棍、躲避和反击取得优势；鲨鱼凭身体惯性、转向和更强的尾部力量扭转局面。每次攻击都体现前摇、加速、接触、余势与恢复，后一个动作承接前一个动作的重心。

角色：Sahur / Tralalero。武器：右手持棍，可投掷回旋镖。写实的重量和反应，适量夸张用于攻击可读性。无新增音效。

## 第一段：尾击碎船与落脚

目标约 6–8 秒；按现有船与海面尺度在 blocking 中校准。

1. 鲨鱼靠近船侧，背鳍/尾部露出形成预兆；身体向一侧弯曲蓄力，头部和前半身保持水中。
2. 以身体转动带动脊柱和尾部，尾端加速横扫船侧。船身先受力倾斜，命中点开始解体；尾部继续扫过，鲨鱼顺势回水。
3. 船的实际碎片受击释放，在重力和初始冲量下落海、碰撞和浮平。Sahur 被晃得失去平衡，低姿势落脚到可站的残骸上。
4. 镜头从尾击接触点跟随到 Sahur 的落脚位置，平顺交还玩家操作。

优先验收：尾端真实接触船体；船的受力与断裂顺序一致；碎片重量；Sahur 支撑脚/重心；鲨鱼水面露出比例。

## 第二段：玩家操作交手

保留当前随机 20–35 秒或 Sahur 血量 <=20% 进入最终交手的条件。当前代码未使用鲨鱼 30% 血量触发，本次方案不恢复该历史条件。

- 玩家可以正常攻击、蓄力、移动、跑步、换方向，以及跳板、游泳、攀爬和操控木板。
- 鲨鱼的咬击/尾扫有清晰的方向和约 0.8–1.0 秒的可读预兆；攻击后的头部暴露与恢复形成可利用的反击窗口，目标约 1.5–2.4 秒。确切窗口在 blocking/游戏验证时与动作一起定稿。
- Sahur 的实际命中引起头部/身体分层受击、偏转和退开，伤害与接触同步。鲨鱼落空后保留动量再恢复，不立刻贴回玩家。
- 玩家成功反击时体现 Sahur 取得优势；若玩家操作阶段很短或处于劣势，最终交手的开头会完整展示势均力敌到占上风的叙事递进。

交互阶段根位移由现有玩家/木板/游泳系统持有。蓄力及重击保持右臂分层与移动兼容；新动画不能通过锁死移动来制造重量。

## 第三段：自动交手与最终败北

基础分镜为 14.4 秒，60 FPS，共 865 个端点采样（源帧 1–865）；下表保留基础编舞时刻。当前 v003 在基础 3.1 秒和 7.2 秒插入 4 秒和 2.4 秒跨板/跃水段，实际主片为 20.8 秒。新时刻、动作与评审见 `traversal-v003-design.md` / `traversal-v003-review.md`。水中游近/爬板的入场另计，平顺接入双方站位。双人动作使用同一时间轴，基于运动木板的局部坐标对齐走位。

| 时间 / 源帧 | 叙事与动作 | 接触/反应重点 |
|---|---|---|
| 0–0.6 s / 1–37 | 站稳并形成对峙；Sahur 低姿势握棍，鲨鱼低位靠近 | 脚稳定支撑，保留上一动作动量 |
| 0.6–3.0 s / 37–181 | **势均力敌**：鲨鱼探咬；Sahur 侧移、用棍挡开并短促反击；双方各退半步重新找角度 | 首次棍/头部交手约 2.0 s（帧 121），明确格挡与退让 |
| 3.0–7.2 s / 181–433 | **Sahur 占上风**：抓恢复空档，右手斜劈命中头侧；鲨鱼偏转退开；Sahur 接一记回旋镖迫使其继续退让，收棍准备下一击 | 斜劈约 4.0 s（241）；投掷释放约 4.7 s（283），命中约 5.5 s（331），接回约 6.6 s（397） |
| 7.2–10.8 s / 433–649 | **鲨鱼逆转**：压低身体，从侧面变向；以探咬牵制 Sahur，接横向尾扫。Sahur 看见尾扫、抬棍抵挡，但被推向板边，最后一次反击落空 | 尾扫受挫约 9.2 s（553）；胸/肩、髋与脚分次承受冲量，板面支撑仍有因果 |
| 10.8–14.4 s / 649–865 | **Sahur 落败**：鲨鱼再次蓄力，重尾击击穿他的防守；Sahur 重心越过板边，握棍手松开，棍子脱手，他落海并失去意识 | 最后尾击约 11.6 s（697），脱手约 11.7 s（703）；重力控制下坠，接入脸朝上的漂流状态 |

时间为 blocking 的目标锚点。评审可在不改变已确认胜负节奏的前提下局部调整间隔；最终输出记录确切源帧、秒数和归一化时间。

### 身体机制

- Sahur 以脚/髋传力，经躯干、肩、右臂到棍尖；左臂用于平衡与护身。蓄力抬棍接斜劈，与此前用户认可的攻击方向一致。
- 鲨鱼以身体弯曲和转向先蓄力，再逐段传到尾根、尾中、尾尖；头、鳍和尾的反应有先后，恢复体现体型惯性与水阻。
- 受击是局部接触先发生、身体随后承受冲量、脚重新找支撑；Sahur 最终因为支撑和防守被破坏而落败。
- 命中来自连续的棍尖/鼻端/尾端轨迹和提前匹配的走位。取消当前命中帧强制跳姿势与大幅整体平移来对齐接触的做法。
- 镜头保持双方在同一画面，能看见棍尖、尾扫方向、板边与落脚点；在逆转和最后尾击时适当收紧，落海后跟随重心与棍子脱手。

### 游戏逻辑与动作所有权

- 玩家操作阶段按现有碰撞/伤害窗口工作；攻击命中与可见武器/鼻/尾轨迹一起校验。
- 进入自动交手时通过过渡姿势与镜头连续衔接，自动段落统一持有双方位移和姿势时间；同步清理之前的蓄力/投掷状态。
- 自动段落叙事接触由对应源帧触发，每个接触只处理一次；倒计时、暂停、混合、走位与姿势使用同一时钟。
- 从水中进入、不同大小/朝向的木板、浮板晃动、玩家靠板边的情况均需验证。
- 结局衔接：失棍、昏迷、脸朝上漂流、头朝岸边、随后起身找棍子的既有剧情。
