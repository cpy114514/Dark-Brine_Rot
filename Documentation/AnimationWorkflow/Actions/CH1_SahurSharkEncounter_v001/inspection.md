# 开场 Sahur / 鲨鱼交手重做：现状检查

阶段：DESIGN。尚未获得本次重做方案的确认，未修改生产动画、骨架或场景。

## 已确定的叙事与角色要求

- 鲨鱼甩尾击碎船；碎片落海并按物理漂浮。
- Sahur 可以在木板间跳跃、游泳、攀爬和操控木板移动，使用正常战斗操作。
- 交手需要有来有回，结局是 Sahur 败北、失去棍子，接入后续漂流上岸。
- 棍子攻击主要由右手完成；蓄力和释放允许移动、跑步和换方向。
- 偏写实的动作与重量；暂不加入音效。

这些来自此前已确认的要求。本次的新分镜、动作与重做范围仍需实际设计确认。

## 当前程序事实

来源：Assets/Scripts/Story/Chapter1/Story1WreckBattle.cs、Story1WreckFinale.cs。

- 当前流程是 Breaking → Fighting → Finale → Defeat。
- 玩家操作阶段每次取样 20–35 秒；Sahur 血量 <=20% 也触发最终交手。当前代码不使用鲨鱼 30% 血量触发，尽管保留了历史字段。
- 最后交手的基准时长为 14.4 秒；入场会根据水中游近/爬板的情况延长。
- 当前段落：站稳 → 棍子反击 → 躲尾扫 → 回旋镖 → 跳跃攻击 → 格挡受挫 → 最后斜劈 → 尾击败北。
- Sahur 以手动 PlayableGraph 混合已有攻击、翻滚、投掷、格挡、受击和死亡片段。鲨鱼使用已有咬击、尾击、受击与威吓 Action。
- 角色动作与世界位移分开控制；木板有实时物理运动，必须在实际运动的板面上校验脚部支撑。

## 制作前优先检查的风险

以下是代码检查发现的风险，不是未经观看就给出的动画质量评分。

1. 命中时 EvaluateHeroPose(contactPhase) 强制采样指定时间，并把混合权重设为 1。它可能形成突变；重做应让命中自然出现在连续轨迹上。
2. 命中时 LateUpdate 会把整条鲨鱼的位置修正到棍尖/胸口，没有将修正幅度作为约束。重做应先匹配双方走位和攻击轨迹，避免依靠最后一帧的大幅修正制造接触。
3. 短时间内同时使用翻滚、回旋镖、跳斩、格挡和斜劈，片段间身体支撑、持棍姿势和动量是否一致尚未实看。需要以批准后的分镜决定保留哪些招式。
4. 尾击必须体现身体转动、脊柱传力、尾端加速与水阻；Sahur 的反应须与实际接触方向及时间一致。
5. 镜头要持续展示双方的攻击方向、棍尖和落脚位置；当前镜头代码的侧面/上方偏移需要在实际角色尺度下确认。
