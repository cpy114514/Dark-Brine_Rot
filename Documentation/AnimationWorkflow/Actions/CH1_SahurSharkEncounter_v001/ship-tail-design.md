# 自主重设计：甩尾碎船 v001

授权：2026-10-07 用户明确要求打斗完成后自主重新设计鲨鱼击碎船，不再提问。打斗的主时间轴、残血/时间触发和水中入场已通过实测与画面检查，进入本段制作。

时间与因果：1.3 秒沿船侧压低身体转向；1.15 秒尾击，局部动作 .65 秒接触（总时刻1.95秒）；.14秒受击船体先倾斜，再由原船碎片自由释放；4.6秒碎片落海和角色恢复操作。保留约6.7秒总时长，避免修改既有玩法节奏。

动作：身体—脊柱—尾根—尾中—尾尖逐段发力；前半身较深，尾尖在接触前才抬出水面，接触后保持余势穿过船侧并沉回水中。鳍、头和尾有不同延迟。船先沿尾扫方向产生平移/倾斜，近命中点碎片初速更大，随后只有重力/水阻和实际浮力控制落点。保留20块物理甲板与202个原船可见碎片。

验证重点：记录未校正的真实尾尖距离；连续采样整个尾击时间，而不在接触帧跳动作或挪鲨鱼；对船受力和释放顺序、尾端方向、头部与船的距离、海面露出和角色落脚分别检查。画面与接触误差共同验收，不以粒子或运镜代替动作。
