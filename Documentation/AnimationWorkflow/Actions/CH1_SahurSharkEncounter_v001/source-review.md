# v001 / v002 制作记录

2026-10-07，开发者选定了 Sahur 的斜劈动作并确认分镜。随后在 GPT 辅助的制作流程中修订角色交手和鲨鱼尾击碎船的动作。

## 动作来源与导入

- 鲨鱼沿用原骨架、网格和七个已有 Action。v001 增加咬击、尾扫和受击三个动作。尾扫的发力从躯干依次传到尾端，受击的摆动逐步衰减。
- Sahur 的斜劈源自开发者选定的 `StandingMeleeAttackDownward`。v001 将动作重定时为 1.6 秒，接触点在 0.9 秒，左手用于平衡。Sahur 导入时复用了同源 Mixamo Avatar，鲨鱼使用 Generic Rig。
- 新动作单独版本化，以 60 FPS 逐帧采样，每个 FBX 导出一个 Action。首次只锁定 Hips 的两个位移轴时验证失败，改为锁定完整根位移后通过。导出时应保留原骨架和旧版本文件。

这一阶段的检查覆盖骨架、时长和导入，脚底接地与武器命中需要在 Unity 回放中验证。后续修订、实测和录像见[最终评审](final-review.md)。
