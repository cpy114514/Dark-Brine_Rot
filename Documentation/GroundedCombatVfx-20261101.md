# 战斗特效：克制、实体接触与短促力量感

2026-11-01 · task039 · Unity6000.3.23f1 / URP17.3

用户否定了 task037 的视觉方向，要求减少浮夸，参考《黑神话》的表现取向。本轮重新制作武器气痕、接触形态和蓄力表现，以短促的实体撞击、尘土与少量暖色亮点为主。方向参考：[官方游戏展示页](https://www.playstation.com/en-us/games/black-myth-wukong/)。项目继续使用自己的模型、动作与程序化特效资源。

## 最终变化

- **普通挥击**：轨迹仅覆盖武器外端，寿命约55–85 ms。去掉整条发白的轮廓、反光边和规则内部光纹，改为低透明度、有方向变化的灰白气痕。
- **确认命中**：原先多层弯曲白线改为接触点向外迸发的短刷痕。形态包含弯曲和纵深，随命中方向定向；最初几帧保留清楚的暖白/暗金亮点，然后破碎退场。金属、木头和一般接触使用不同颜色。
- **接触尘团**：重用现有三维密度资源与射线步进材质，新增非自发光的受光尘土分支。尘团有内部密度、散逸和实体遮挡，不随相机转向。普通命中约0.34秒、重击约0.55秒退场；亮点寿命更短。
- **蓄力**：取消大范围光环，将少量细碎暖色纤维收在武器附近并随进度变化。修正了早期缩小形态时被不透明武器遮住的问题；纤维落在武器外侧。
- **重击与落地**：降低反馈范围，尘土使用不规则低矮波瓣；碎块由12块减至7块，并降低尺寸和弹跳高度。
- **爆炸**：热核亮度降低、冷却更早；让密度在有限体积边界之前归零，避免冷却烟体暴露方形代理体边缘。保留真实三维密度和遮挡。

实际命中与最终武器姿态仍决定播放时刻。伤害数值、碰撞判定、输入、相机反馈和动画资源没有被这一轮改写。Boss 使用共享武器轨迹系统的部分会同步获得新材质表现；各自的专属声波等效果继续使用原系统。

## 预算与生命周期

全场最多同时显示3个接触尘团，默认20步、低画质16步；保留最多2个爆炸体积、16个接触槽、每帧4次新接触的既有预算。未获得尘团预算的命中仍保留短刷痕。网格、材质和属性缓冲复用；没有逐片刚体或新增粒子系统。

接触尘团仅在需要时租用相机深度。结束、清空、拥有者禁用或场景退出会清理对应可见节点；全局清理归还深度选项。所有新增尘团节点归属原有全局池，释放时随池销毁。

最终原生录制15项检查、尘团专项16项检查均通过，运行及着色器错误0。共373张连续原生帧，按30 fps编码为12.43秒视频。`BrineVFX.BoundedWorld` 组件脚本采样P95为0.5418 ms；该数字不包含完整场景和GPU开销，未据此声称成品帧率。

录制使用真实玩家预制体、原生攻击动画和虚拟手柄，训练柱具有实际 `Health`；位置在第一岛原有 Environment+Lighting 中，测试角色不会存档。固定步长录制用于动作和视觉审核，不能作为实时帧率证据。组件脚本采样不包含全部GPU渲染或初始化成本。

早期 `grounded-a` 版过淡，未作为最终成果；`grounded-b` 和 `final` 是后续调试记录。`before` / `before-ready` 的新基线尝试因测试启动条件失败，没有有效比较视频；旧方向的原始实景证据保留于 task037。

独立相机的第二次 `Camera.Render()` 不能依赖第一次已提交的手工草批次。因此最终检查图选自连续录制的首遍JPG帧，不使用早期额外PNG捕获来比较草密度。
