# 自主体验改进：恢复指引与补给反馈（2026-10-20）

本轮针对已实现的近战恢复营地补足发现与确认环节：

- 生命降至 40% 时，指引实际存在且启用的恢复营地，优先于弹药提醒；恢复到 75% 后收起，避免阈值附近反复闪烁。
- 提示显示当前治疗按键及剩余治疗包数量。治疗包耗尽时只引导营地恢复，不提示不可用的治疗动作。
- 优先指引可用恢复点；仅有冷却中的点时保留目标并显示真实倒计时。纯弹药点不会被误标为恢复点。
- 进入营地附近后收起导航方框，提示按 F 补给，避免方框文字与营地交互提示重叠。
- 补给成功后显示实际增加的 HP、SP 和弹药，包括上限造成的部分补充；状态全满时明确显示 Nothing consumed，冷却仍然可用。
- 保留健康玩家的原有步枪与低弹药引导，补足初始化时尚未出现的步枪组件查找。
