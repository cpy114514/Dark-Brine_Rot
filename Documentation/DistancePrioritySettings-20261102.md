# 远景优先画面配置 — 2026-11-02

按用户要求把预算优先分配给更远的可见范围，并降低像素、纹理和阴影开销。

| 项目 | 原推荐配置 | 新推荐配置 |
| --- | --- | --- |
| 草地空间淡出 | 140–176 米 | 200–240 米 |
| 草地 CPU 驻留上限 | 190 米 | 260 米 |
| 树木外层剔除上限 | 550 米 | 750 米 |
| 旧植被外层剔除上限 | 260 米 | 350 米 |
| LOD bias | 1 | 1.5 |
| 渲染比例 | 85% | 75% |
| 纹理 mipmap 限制 | 1 | 2 |
| 阴影距离 | 180 米 | 60 米 |
| 阴影贴图 | 1024 | 1024 |

保持 60 帧上限、VSync 关闭、FXAA、基础色调和阴影；Bloom、暗角、动态模糊和 Pixel Style 继续默认关闭。UI 仍使用原生分辨率。纹理限制只影响适用的 mipmapped 纹理。

第一岛玩家相机已有约 3020 米远裁剪面，本次不修改相机或场景。WorldPerformanceManager 的物体和空间分组剔除共用新的范围常量，避免只提高物体范围却仍被旧分组提前裁掉。远处继续使用已有轻量网格，草地阴影仍在原来的 24–36 米范围淡出，不会跟随可见草地扩展到 240 米。

上述米数是外层上限；每个植被实例仍受原有 LOD、FOV、尺寸、遮挡和距离到包围盒边缘的计算影响。LOD bias 提高会延后原生 LOD 切换，也可能增加可见细节开销，不能把表中上限解释成每棵树都必定显示到该距离。[Unity LOD bias 说明](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/QualitySettings-lodBias.html)

## 生效方式

新玩家首次启动与“恢复默认”采用这套新预设。保留首次初始化标记和已有玩家自定义配置的逻辑，不进行全体玩家强制迁移。作为本轮明确的画面调整，本机已单独应用新的画面预设及 60 帧上限，下一次 Play/游戏启动生效；音量、按键、难度、语言、视角和显示模式保留。应用前的本机设置保存在本轮本地证据中。

## 验证与限度

- Unity 6000.3.23f1 重新编译通过。
- 21 项配置检查通过：首次保存、再次读取、旧配置保留与无效值回退等。
- 15 项原生剔除夹具检查通过：草地、旧植被、树木在旧边界之外仍可显示，超过新边界会剔除，接近后能恢复，包围盒边缘规则和原网格保留。
- 真实标题场景 15 项检查确认新配置已应用；通过菜单保存自定义值后，第二次启动的 3 项检查仍保留玩家选择。
- 实际 Mavis/FoliageWind 着色器的固定投影测试通过 5 项检查：同一几何、材质、像素投影下，旧范围在 180 米可见像素为 0，新范围在 180 米为 54,752、220 米为 41,003、245 米为 0；草地阴影范围保持一致。数值来自正交平面夹具，用于验证真实着色器的距离覆盖与淡出，不是岛屿画面或草地密度估算。
- 以上共 59 项检查。测试后的原 PlayerPrefs、场景工作区和存档核对恢复；随后才按本轮请求单独应用本机画面预设，并核对其他设置未变。

更远的范围会增加潜在几何和提交量，降低像素/阴影/纹理开销不代表一定抵消全部成本。本轮不声称整体 FPS 提升或独立 Player 帧率达标，没有构建新安装包。已有 606 个植物 Prefab 缺失问题保持原状。
