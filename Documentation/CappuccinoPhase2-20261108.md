# Cappuccino Assassino 第二阶段升级

实现日期：2026-11-08。使用当前 Unity 6000.3.23f1 / URP、原有双刀蒙皮、14 个拟合骨骼和隐藏 Humanoid 动画源。没有替换模型、Avatar、绑定姿势、第一阶段攻击 Clip 或死亡 Clip。

## 战斗变化

第一阶段的 TwinSlash、DashThrust、Whirlwind 保留原有动作时钟、伤害窗口、追击、退避与命中路径。枚举值追加在末尾，保留旧序号。Boss 保留固定 999 最大生命、现有 50% 阈值、强化后回复 200 生命和 3 秒行动锁定；没有增加伤害或生命倍率。

第二阶段以四个新技能为核心；距离、独立冷却和前两次招式影响加权选择，禁止连续选择同一新技能。新技能冷却时可以使用原招式。新攻击沿用 PlayerHealth 的格挡、无敌、完美闪避、共享受伤恢复和命中反馈。

| 技能 | 动作长度 | 起手 | 实际判定与应对 | 独立冷却 |
|---|---:|---:|---|---:|
| 瞬影连斩 / Afterimage Requiem | 3.35 秒 | 0.70 秒 | 三次有加减速的切入；切入前锁定方向，约 0.94 / 1.64 / 2.34 秒判定；侧闪后反击 | 7.5 秒 |
| 奶沫回旋 / Crema Cyclone | 3.25 秒 | 0.85 秒 | 两周回旋、两次伤害窗口；轮廓与真实范围一致，可提前退圈 | 9 秒 |
| 摩卡俯冲 / Mocha Descent | 3.45 秒 | 0.65 秒 | 跃起、悬停、下劈，1.95 秒落地；落点提前锁定。低位环形冲击波从半径 3.8 米扩展至约 13.6 米，可跳跃规避 | 11 秒 |
| 咖啡狂潮 / Ristretto Tempest | 5.15 秒 | 0.85 秒 | 交替双刀三段后重新蓄力，延迟重击；约 1.12 / 1.90 / 2.65 / 3.91 秒判定，可利用末段蓄力绕侧 | 16 秒 |

只在当前有效窗口内判定，掉帧跨过整个窗口不会补发伤害；每段最多结算一次，遮挡检查阻止隔墙命中。动作收招后另有约 0.95 秒硬直，组合技约 1.32 秒（使用原有回血后 1.1 倍行动时钟）；随后进入原有侧移。直击与冲击波受玩家共享受伤恢复限制。

## 阶段转换

阈值触发时取消当前攻击和旧判定，进入独立 PhaseTransition 状态。专用 4.2 秒全身动画包含失衡、后撤、压低重心、双刀蓄力、抬臂展开与新架势。蒸汽使用两条网格带，能量释放使用羽化网格环与短暂镜头震动。结束后才提交 FightPhase=2。

玩家保留控制；不修改玩家控制锁、Time.timeScale、镜头跟随对象或构图。致命伤由原死亡系统处理，不因演出复活；对象禁用后可继续剩余转换，目标死亡则回归并重置整场战斗。

## 动画和效果

- 六个新 AnimationClip / Animator 状态：转换、四种技能、第二阶段待机。复用项目现有 Quaternius UAL1/UAL2，重新编排全身姿势与左右手独立关键帧，针对杯身比例调整双刀轮廓。
- 动画、朝向、CharacterController 位移、判定和声音共用动作时钟。原骨骼转移器继续校正站姿、脚底和刀刃地面接触。
- 沿用现有武器网格轨迹；四组预热蒙皮快照组成有限残影，冻结在世界位置。Unity 6.3 使用 BakeMesh(mesh,true)，避免重复应用源角色的 2.52 倍缩放。
- Resources 内 CremaMesh 材质直接引用新增 URP Shader。两条蒸汽带及一个羽化环替代大量普通粒子。
- 四个原创合成 WAV：蓄力、刀刃重音、落地与 120 BPM 节奏。音频跟随音量设置与暂停。
- `Tools/BuildCappuccinoPhase2.cs` 重建新增 Clip/状态，`Tools/BuildCappuccinoAudio.py` 重建音频。简化后的曲线以 120 Hz 检查误差不超过 0.0015；超出则保留原曲线。
