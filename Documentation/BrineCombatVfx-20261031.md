## 视觉设计与接入范围

本轮以冷灰、盐白的刃风和暖色热体积为统一语言。武器的力量主要通过形态、真实轨迹、接触面的反馈以及短促的明暗变化表达。颜色和亮度留出人物、敌人动作与环境的可读空间。

| 战斗层级 | 实现 |
| --- | --- |
| 普通攻击 | 按最终武器姿态生成带厚度与弯度的动态网格；叶形收束、盐白切边和内部流纹；确认命中后使用两层弯曲接触形态 |
| 蓄力与重击 | 随实际蓄力进度变化的武器周围收束曲面；重击使用五层空间弯曲形态，增加接地压力、碎片和短促反射光 |
| 双刀、旋转、跳斩 | 双手各自记录实际武器轨迹；重击分类不依赖敌人是否能够被击退；跳斩与落地调用接地反馈 |
| 格挡、射击与回旋武器命中 | 根据既有命中类型使用较小的接触层；金属有暖色接触变化；保留子弹、回旋武器与剧情鲨鱼的原始接触点 |
| Capri 与奶龙武器轨迹 | 接入相同的曲面轨迹系统，在最终姿态修正后采样，保留各自伤害窗口 |
| Bombardino 爆炸 | 使用三维密度纹理与体积光线步进，包含内部流动、热核、外层冷却、体积遮挡和不规则消散；不再调用原来的爆炸粒子堆叠 |

接触效果由原有接受伤害的回调触发。近战使用目标碰撞体的表面入口修正显示位置，避免向下挥击的效果埋进目标内部。武器采样放在执行顺序 18000，晚于现有角色、船体与剧情姿态修正。伤害数值、命中窗口、角色动画资源与输入映射保持原有逻辑。

连续攻击会保留上一段轨迹的自然消散，同时切断两次挥击之间的连接；切换武器后副手残迹也会继续正确退场。

## 环境与性能

大型接地效果先查询真实碰撞表面，再缓存贴地网格。实体碎片受光照并投射阴影；木质表面使用较窄的碎片形态。碎片仅用于表现，不增加逐片刚体模拟。爆炸带暖色贴地反馈和短时点光源。

- 全场共享对象池：默认 16 个接触效果、6 组地面反馈、2 个点光源。
- 每个来源最多 8 个接触效果；每帧最多接受 4 个新接触；最多同时显示 2 个体积爆炸。超出预算时跳过额外视觉请求。
- 每只手最多 32 个轨迹采样点、320 个网格顶点。运行时复用顶点、索引、射线结果和材质属性缓冲。
- 体积密度为 64³ R8 周期纹理，材质共享。低画质使用 24 步，默认 36 步，上限 48 步。
- 只有体积效果需要时才临时请求相机深度，结束时恢复原来的相机选项。没有新增全屏折射或场景颜色复制需求。
- 编辑器脚本重载前释放拥有的运行时网格，重载后重建；已验证全局池数量与角色节点数量没有增长。

第一岛测试中的 `BrineVFX.BoundedWorld` 脚本更新 P95 为 **0.6651 ms**。这是本机编辑器的组件脚本采样，未包含全部地形渲染、生成瞬间的投影查询与 GPU 开销，也不能据此推断成品包帧率。当前编辑器没有提供有效的 GPU 帧耗时数据。

## 调整与维护

主要美术入口是 `Assets/Resources/Combat/BrineVfxStyle.asset`。可调整刃风颜色、切边颜色、暖色接触、热核、火体、烟体、可见度、接触尺寸和距离预算。池容量在建立全局池时生效，修改后重新进入 Play。

源文件分工：

- `CombatImpactVisuals` 保持原战斗调用接口，排队采样武器并解析接触类型。
- `BrineVfxGeometry` 与 `BrineWeaponTrail` 负责曲面与轨迹形态。
- `BrineVfxWorld` 管理共享池、强度、光源与相机深度租用。
- `BrineGroundWake` 负责真实表面的压力形态和实体碎片。
- `BrineSurface`、`BrineStone`、`BrineThermalVolume` 分别负责刃风、实体碎片与体积材质。

原有奶龙声波、海面、环境风、剧情破船与其他专属表现继续使用既有系统。当前覆盖的是上述战斗层级与接入点。

`Tools/InstallBrineVfx037.cs` 使用 Unity 原生资产 API 创建材质、密度资源与风格配置；`ReviewBrineVfx037.cs` 和 `ReviewBrineVfxVideo037.py` 提供可重复的原生录制与打包入口。测试前备份存档与场景配置，测试后恢复。未生成 Windows 安装包，未提交或推送仓库。
