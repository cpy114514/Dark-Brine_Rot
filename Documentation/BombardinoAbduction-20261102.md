# 飞机抓走 Sahur 与第二岛开场衔接

2026-11-02 · task052 · Unity 6000.3.23f1 / URP17.3

本轮保留“飞机战败后抓走 Sahur，飞往第二岛并抛落，随后醒来”的既有剧情，针对接触、身体动作、镜头与开场交接做优化。未更换角色模型、Avatar 或控制器，未编辑原动画资源或场景文件。

## 动作与镜头

- 抓取由瞬间设置局部坐标改为约 0.4 秒的站姿至吊挂姿态混合。沿用项目内 `CH1_SahurAirHit_v214` 动画，增加只归本段演出所有的双臂接触求解。
- 双手目标根据实际肩部与臂长建立，锚定飞机会俯仰的可视模型。修正导入模型局部左右轴反向造成的交叉抓点。身体带小幅衰减摆动，脚保持悬垂与屈膝形态。
- 飞机接近和爬升使用平滑路径。俯冲时镜头留住 Sahur，让飞机从上方进入，避免镜头先追到空中而丢失角色。
- 释放时明确脱离飞机父节点；角色使用带初始前向速度、持续向下加速的轨迹，飞机继续飞离。落地前不再强行转成直立姿态。
- 接触地面时保留末段受击姿态，按实际变形网格最低点校正高度，随后短促遮黑。第二岛原有睁眼、起身与对话在黑幕下接管，避免站立姿态闪现。

## 场景与控制交接

旧逻辑在 `BombardinoAbduction.Playing` 时跳过第二岛自动开场，却未在落地后重新启动。本轮增加 `SecondIslandAwakening.BeginAfterAbduction`，明确在着地、解除飞机控制后创建一次开场。直接打开第二岛及继续存档仍保留原自动创建条件。

新场景使用其原有 Sahur 实例，保留第二岛自身的任务、棉花糖移动、存档和首次移动前保护组件；在加载黑幕期间转移旧实例的物品数量、穿戴、武器所有权/选择、弱点眼镜状态、弹药、血量和体力，再移除旧实例。无需临时拼装第二岛组件，也不保留两个可控制角色。

暂停冻结本段动画与路径，黑幕在暂停菜单打开时让出画面。中断演出会停止本组件协程，销毁专属 PlayableGraph，归还动作所有权、碰撞胶囊和控制。原角色控制器与攻击动画恢复原本的启用状态。
