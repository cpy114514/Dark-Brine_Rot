# 开场教程与鲨鱼追逐修复（task054）

用户范围：缩短 WASD 教学；修复蓄力完成后的姿势突变；稳定鲨鱼前半身；Space 跳水输入门保持起跳预备；修正自由游泳爬板方向；简化为鲨鱼从后方追、Sahur 爬板；让真实尾鳍在趴下时从上方扫过。

## 实现

- 行走教学最低体验从 4 秒缩到 1.5 秒，仍要求真实移动；游泳练习从至少 6 秒/8m 改为 2.5 秒/6m。跑步与攻击教学保留。
- 蓄力的松手输入门每帧重申完整分层蓄力姿势，再捕获上半身交接姿势，并在释放初始 0.12 秒过渡。避免 Animator 在两次手动采样之间重新求值后，把待机姿势当作蓄力末帧。
- 跳水前完成原收武器动作，过渡到现有 `PLAYER_JumpStart_v006` 的屈膝压缩姿势；等待真实 Jump 输入时持续采样，之后与原空中动作衔接。
- 三套实际 Animator Controller 的 `Wreck Climb` 全部改为已有方向修正版 `PLAYER_Climb_v241`，速度匹配 rider 的 1.15 秒。此前 Grounded 仍用 Quaternius 爬行动作，Gameplay/Rifle 仍用反向 v006。通过原生 Animator API 安装，原动画 FBX 未改写。
- 游泳追逐保持单一前进路线，鲨鱼在后方跟随；去掉三次交错扑咬、横向闪躲、回头扭转和相关切镜。保留爬上真实浮木、持武器反击及后续失败叙事。
- 表面游泳时约束 Body/Head 的次级偏转和侧倾；保留根朝向、扑咬和跃起的动作意图。没有缩放鲨鱼或修改模型网格。
- 甩尾实验已回退到原来的趴下段：新的两版尝试均产生大幅身体弹跳或尾鳍出画。甩尾从上方掠过仍待重新制作和验证。

## 验证与限制

`.codex/opening054/` 保留基线、逐帧截图、原生视频、接触检查、专项测试和回退副本。所有固定步长录制是复现用模拟，不是实机 FPS 基准。

`baseline`：3037 帧，2 个教程真实接触、3 个电影接触、70HP，流程通过但用户报告的视觉缺陷可见。`after-1` 因改变扑咬前半身姿态影响教程接触而拒绝；已将前向约束限定为表面游泳。`after-2` 虽然 2888 帧流程通过、47 个独立几何采样没有木头交叉，但松手交接仍有约 77° 单帧跳变，趴下段出现约 19m 的原生躯干解穿插位移，不能作为视觉验收。

`free-climb-3` 专项：6 项通过、70 个爬行动画帧，采样胸部正向与朝板方向点积最低 0.742，实际落回实体甲板并恢复地面控制；无运行错误。夹具使用真实骑乘组件从游泳状态进入其生产爬板路径，隔离本次朝向/恢复修复；没有把它描述为完整自动抓板输入策略验收。早期夹具重用已清理的 InputSettings、以及自动靠近条件不满足的 take 均保留且不计通过。

`after-3` 流程 2887 帧通过，蓄力松手臂部变化约 0.024°、0°、0.039°，行走 1.533 秒，追逐能看到鲨鱼；但尾部方案出现 14.39m 身体分离，尾鳍超出镜头，故尾部实验已回退。回退后的整段最终版本尚未重新回放。飞机双爪抓取仍未实现：现有双手接触点位于飞机腹部，不证明双爪接触。不以接触计数代替视觉验收，不声称人类 FINAL/APPROVED。
