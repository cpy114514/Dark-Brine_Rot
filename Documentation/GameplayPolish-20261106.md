# 操控、战斗与稳定性复核 · 2026-11-06

分支 `codex/gameplay-feel-polish`。基于已存在的控制预设、动作遮罩、跳跃缓冲、离地宽限、局部命中顿帧和三套武器实现做局部修正。旧场景与用户未提交改动保留；本轮源文件快照及开始时的完整补丁在 `.codex/gameplay-polish/source-before/`、`workspace-before.patch`。

## 实际修改

- 普通翻滚结束先保存继承速度，再清空翻滚状态，继续向当前输入方向过渡。旧实现先清零 `rollInheritedSpeed`，随后用这个零值计算退出速度，造成一次明显减速。30Hz原生前向移动测试退出速度从4.114恢复到9.6m/s，翻滚时长、上限和保护窗不变。
- 鸡鸭鹅命中产生的推力独立于自主移动速度，并对线性衰减曲线做逐帧积分。旧实现每帧把推力加进上帧速度，导致额外惯性和对步长的依赖。6m/s、.28s的测试中，旧峰值6.686m/s，修正后首个已采样帧为5.286m/s（推力已开始衰减）；30/60/120Hz均通过不叠加的检查。恢复位置同时清掉旧推力。
- M4A1增加120ms单次按下缓冲。冷却期间的新点按可在下一次合法射击时执行；成功发射即清除，暂停、失焦、不具备武器操作条件、装填、停用和弹药恢复会清除缓冲。旧实现只查询当前是否按住，短点按在冷却中释放即丢失。射速及弹药消耗不变。
- 现有效果打磨另见 `ExistingVfx-20261106.md`，覆盖命中、轨迹、尘土、爆炸的节奏与材质，没有增加数量。

生产修改仅涉及 `ThirdPersonPlayerController.cs`、`SahurRifleCombat.cs` 与上述四个共用VFX文件；场景、AnimatorController、原FBX和输入绑定没有为这轮重写。相机与原有动作衔接通过检查的部分沿用既有实现。
