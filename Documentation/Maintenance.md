# 项目整理与优化

## 保留范围

本次维护保留当前场景、手动调整的棍子 Transform、模型、材质、动画状态机、控制参数、着色器、贴图导入设置、包依赖和项目配置。既有未提交修改继续保留。
Unity 资源目录及 GUID 不变；根目录六张历史截图整理到 `Documentation/Previews/`，没有删除资源。

## 实现

- `OceanWorld` 按当前分辨率和视距缓存前方/全覆盖两种海面网格，反复切换视角时复用。改变生成尺寸或关闭组件时释放两份缓存。
- 顶点和三角形数据保持原样。顶点数允许时采用 16 位索引，省去 Shader 未读取的 UV 通道。
- 前方网格的幂函数按行和列分别计算，避免每个顶点重复运算。中档 160 行、136 列时，两类幂计算由 44,114 次减为 298 次。
- 水面视距参数仅在数值改变或材质重建后上传；常用 Shader/Animator 属性采用缓存 ID。
- 播放模式缓存海洋和太阳所用灯光，灯光被销毁或停用时重新查找。编辑模式仍保持实时查找。若以后增加运行时灯光切换系统，应显式更新此缓存。
- 修复海水材质缺失时提前退出清理、导致天空材质无法释放的问题。
- 第三人称控制器复用每帧相同的朝向计算；动作映射、按键与运动数值保持原样。

## 验证

- 优化前后比较 80、160、300 三种分辨率，各两种覆盖形状：顶点位置和三角形连接的 SHA-256 一致。
- 通过 Unity 实际编译检查，并检查场景中的组件及资源引用。
- 对 Assets 内非 C# 文件、Packages 和 ProjectSettings 做修改前后汇总哈希核对：汇总值发生变化。核查发现期间包清单被外部更新，Hackatime 从绝对本地路径切换为 Git URL；此更新予以保留，没有回写旧配置。主场景文件最后写入时间仍为维护前，场景未标记为未保存，人工棍子 Transform 保留。
- 当前场景无缺失脚本，三个自定义 Shader 无编译错误；前方/全覆盖网格往返切换均复用原网格对象。
- 273 个资源文件检查结果：缺失 `.meta` 为 0，重复 GUID 为 0；内容相同的 FBX 为 1 组（3 份）。
- `Tools/audit-project.ps1` 可复查缺失 `.meta`、重复 GUID 和内容相同的 FBX。

这次主要减少脚本重复工作、网格重建和单张网格存储。两种视角都使用后会额外常驻另一份网格，这是避免切换卡顿的内存取舍。没有降低画质，也没有实测并承诺 FPS 提升。
