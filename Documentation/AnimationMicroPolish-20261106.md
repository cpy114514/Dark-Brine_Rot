# Sahur 动画微调

本轮只修改 `Assets/Game/Prefabs/Characters/Sahur/Scripts/SahurRifleAnimation.cs` 的持枪/瞄准方向交接。现有移动、棍、双刀动画、动作时间线和游戏判定继续沿用。没有新动画、框架或IK系统，也没有更改Boss动画。

## 具体问题与调整

原实现已经平滑持枪高度，但未瞄准时直接选择低持枪方向，瞄准时直接选择准星目标。40°俯角的原生回放测出进入/退出瞄准的最大单帧枪身旋转为42.697°/45.403°，形成可见姿态切换。

现在用一个独立的视觉权重在两个现有目标之间做球面插值，80ms内交接，起止姿态保持原算法。开火期间立即使用真实瞄准目标；第一次持枪/重新接管也直接初始化正确姿态，避免从旧状态插值。枪口发射逻辑、相机和输入没有改动。

| 参数或行为 | 原值 | 本轮 |
|---|---|---|
| 低持枪→瞄准方向交接 | 直接切换，0ms | 80ms线性权重、方向球面插值 |
| 瞄准/射击姿态结束→低持枪 | 直接切换，0ms | 80ms交接 |
| 开火帧对准目标 | 立即 | 立即 |
| 持枪高度aimBlend | 8/s，125ms | 保持 |
| 握点平滑指数系数 | 14/s | 保持 |
| Rifle Idle→Move过渡 | .12，HasExitTime=false | 保持 |
| Rifle Move→Stop / Idle过渡 | .13 / .14，HasExitTime=false | 保持 |
| 步枪移动方向参数阻尼 | .09s | 保持 |
| 移动/持枪层权重速率 | 12/s | 保持 |
| 射击层目标权重/变化速率 | .22 / 5每秒 | 保持 |

表中Animator过渡duration是序列化原值；本轮未改控制器。完整三套控制器状态、过渡、层权重和角色配置保存在 `AnimationMicroReview/audit-before.json`。源文件回退副本在 `.codex/animation-micro/source-before/`，只恢复本轮的SahurRifleAnimation副本即可撤销本轮生产修改。

## 验证

- 实机前后同样60Hz输入回放：最大单帧旋转降到进入10.035°、退出11.794°。不是全部视角下的最大值保证。
- 开火时枪口对准误差前后均约.052°，验证没有因为视觉过渡而让发射方向滞后。
- 查看原生帧序列，确认姿态逐步交接、双手仍随现有握枪解算保持接触；原始帧在 `.codex/animation-micro/before-rifle/frames` 与 `after-rifle60/frames`。
- 43项原生Play Mode检查通过：移动启动/停止、急转、斜向限速、跳跃落地、翻滚、棍/双刀连击、移动攻击、蓄力、旋转、格挡、步枪瞄准/射击、棍投掷及返回。没有记录运行错误。普通移动起步仍1帧，达到九成走速约117ms，停止约100ms。
- 340项资源检查通过，原动作引用和基础播放速度、层遮罩边界及Prefab脚本引用有效。重新编译成功。JSON报告保存在 `Documentation/AnimationMicroReview/`。

## 保留内容与限制

没有证据要求改动普通走跑、落地、棍或双刀的原动作，因此本轮没有对这些动作另作美术修改，也不宣称修复了所有滑步。未新增脚部IK，现有脚步仍取决于原动作与地形。验证以原生脚本输入、可见帧和契约检查为主，未穷尽所有斜坡、贴墙瞄准角度与整场战斗的人工审美检查；建议试玩关注高低瞄准反复切换及边走边开火。旧构建未重新打包。
