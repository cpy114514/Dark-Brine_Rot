# Dark Brine_Rot 美术精修记录

这轮把两座岛的环境当成玩家行走时依次看到的一组画面。岛一通过盐蚀石墙、船木和旧帆布交代海边营地的用途。岛二把甜点地貌、河道和采样工具串成一处有人工作过的场景。菜单沿用手绘 Sahur，以墨绿、帆布白和黄铜色区分背景、正文及交互信息。

| 玩家看到的问题 | 已落地的改动 |
| --- | --- |
| 岛一 Shore Camp 容易被旁边的岗楼压过去，补给箱像孤立的测试道具 | 用回收帆布、桅杆和拉索围出营地一侧。岗楼的砌石随塔身转向，仍使用原有 650 个三角面。路牌前保留步行空间。 |
| 岛二河边的采样勺像封闭的扁球，部分甜点与坡面分离 | 换成有厚度和凹面的勺斗，增加凝固巧克力、支点销和刻度。两只已有货箱组成操作台，上面放实际比例的饼干样品。核对 202 组甜点的网格与地面接触，落稳其中 17 组。 |
| 卡布奇诺的双斩和突刺轮廓接近，受击时额外尘团掩盖接触点 | 双斩先架开两臂，突刺先把一把刀送到前面瞄准。刃迹分别使用短弧和更窄的刀尖痕迹。受击由现有伤害确认反馈负责，踉跄尘贴地发出。 |
| Chicken Bro 用固定循环跟随速度不同的位移。Sahur 站在巧克力里会因水流推动而带出走路步态 | Chicken Bro 的走跑循环根据实际速度更新。巧克力水流的位移从 Sahur 的步频取样中扣除，涉水阻力与漂移仍由原控制器处理。 |
| 设置页有空行，战斗时大血条抢画面，探索时武器说明占四行 | 回收设置空行，压窄 Boss 条与数值布局，延迟伤害显示使用黄铜色。武器栏只提示当前武器与已可切换的选项。糖果花园、仙女和 Hollow 的操作提示突出按键。 |
| Hollow 入场时出口牌压进镜头 | 把牌贴回后墙并将入场位置移入前厅。入场时优先看到窑门、Pip 和墙面图案。目标卡以加粗任务文字区分旁白。 |

## 验证

- Unity 6000.3.23f1 编译通过。扫描了构建列表的 9 个场景，14 个由场景直接或间接引用的项目 Shader 通过编辑器检查。序章船与鲨鱼、岛一、岛二、Hollow、菜单和卡布奇诺有实机画面。
- 岛一从 Main 加载了四个子场景。使用生产 Chicken Bro prefab，在海岸地面观察到约 4.8 m/s 的跑动和一次扑击。新增营地装饰没有阻挡用碰撞体。
- 卡布奇诺的双斩和突刺分别进入有效窗口并扣除 Sahur 7 和 11 HP，各触发一条实际受击反馈。
- 岛二重跑 6 条跨河或沿岸路线、4 项巧克力接触检查和 5 个画面检查。50 个动态黑板和 6 个场景标牌通过回归，仙女提示在暂停时收起。Hollow 实测进入与返回地表。
- 测试使用隔离存档。4 个正式存档文件与快照逐字节一致。当前验证范围为 Unity 编辑器。全流程通关、每个 Boss 的完整战斗、独立构建及其帧时间仍待验证。

构图参考采用从接近路线组织地标和用背景留白衬托主体的方法。营地从道路一侧读形状，采样站以倾斜长柄在河岸剪出独立轮廓。参考 [Naughty Dog 的关卡引导讲座](https://media.gdcvault.com/gdc2018/presentations/DShaver_Invisible_Intuition_GDC2018.pdf) 与 [《Uncharted 4》环境叙事讲座](https://gdcvault.com/play/1024310/Art-Direction-Bootcamp-Cinematic-Environment)。
