# 战斗特效更新与独立质量设置

按“先做新特效，再接档位”的要求，先实现并渲染检查武器、材质接触和 Boss 局部效果，再完成 Low / Medium / High。所有修改直接在 Unity 项目中；没有改伤害、弹道、敌人种类、Boss 顺序、动画片段或攻击预警时序。

## 本轮实际特效改动

| 部分 | 实现 |
|---|---|
| 棍与双刀 | 原网格轨迹继续采样真实武器位置；双刀改为更窄、更短的冷灰刃迹，持续时间为原轨迹的 78%，棍保留原厚重空气拖痕。没有扩增轨迹数。 |
| 命中 | Flesh 接触不再无条件喷土尘；岩石、沙、土、木才产生适用的尘云。金属保留短火花，植被使用较轻、扁平、较慢下落的碎片。 |
| 可复用材质响应 | 新增 `CombatSurfaceResponse`：显式组件优先，其次现有角色响应、岛屿海拔和导入名称回退。支持 Rock / Sand / Soil / Wood / Metal / Water / Vegetation。原 Flesh、Wood、Metal 的枚举编号不变。 |
| 落地/重击接地 | 现有投射到地面的压痕与碎屑采用地表色；沙粒尺寸为原固体碎屑的 38%，土屑为 70%；显式木质标记控制细长木片，不受模型名称覆盖。 |
| M4A1 枪口 | 用一份复用的三面渐细网格替换旧折线星形闪光；沿真实枪管方向摆放，约 45ms 火舌转成同一网格上的淡冷却烟，总寿命 140ms。没有额外烟粒子或新弹壳发射器。 |
| M4A1 弹着点 | 移除原 12 个十字线弹着池；真实场景碰撞进入共享材质反馈池。已被接受的角色命中继续走现有 CombatHitFeedback，避免重复叠加。弹量、射速、伤害和发射方向不改。 |
| Cappuccino | 既有双刃轨迹采用窄刃风格；原受挫/突进尘土明确使用土质色。触发时刻不改。 |
| Nailong | 原六颗装饰水滴沿实际装饰飞行速度拉长，速度降低后回圆，保持近似体积；碰撞主水球、判定半径、伤害、数量和回收寿命不改。 |
| Bombardino | 保留现有热核、烟层和地面冲击；新增独立采样预算、次级烟层和热扭曲控制。没有新增能力、预警或爆炸层。 |

主要新组件：`Assets/Scripts/Effects/BrineMuzzleFlash.cs`、`CombatSurfaceResponse.cs`、`CombatVfxSettings.cs`。复用既有 `BrineSurface` 着色器、共用池、固体碎片网格和原生水滴材质，无新外部依赖或下载资产。

## 质量与反馈设置

设置 → GRAPHICS → **VFX QUALITY**；循环选择 LOW / MEDIUM / HIGH 后按 APPLY & SAVE。退出未应用的设置不会改变运行画质。首次默认 High，保持现有主要效果。分辨率、Render Scale、纹理、全局 Unity Quality 与此选项分开。

| 项目 | Low | Medium | High |
|---|---:|---:|---:|
| 热体积采样上限 | 20 | 28 | 原资源值，目前 36（上限 48） |
| 尘云采样 | 12 | 16 | 20 |
| 新发射尘云并发预算 | 1 | 2 | 3 |
| 次级六向烟层 | 关闭 | 保留 | 保留 |
| 热扭曲/不透明缓冲请求 | 关闭 | 关闭 | 启用 |
| 无阴影接触补光 | 关闭 | 保留 | 保留 |
| 碎屑与可缩放装饰粒子比例 | 40% | 70% | 100% |
| 轨迹每帧插值步数上限 | 3 | 4 | 6 |
| 环境尘土距离 | 30m | 55m | 85m |

主命中轮廓、枪口、投射物、攻击轨迹与 Boss 预警保留。原共享池容量及每帧发射上限没有扩张。质量改变不会重建整个池；新碎片数量按新档位生成，已有碎片自然结束。活动体积采样和烟层在恢复模拟后更新，High→Low 会释放本系统申请的不透明缓冲。

设置 → GAMEPLAY 新增：

- **CAMERA SHAKE**：Off / Reduced / Full，分别为原共用镜头冲击的 0 / 35% / 100%。不改玩家鼠标输入或武器后坐力动画。
- **INTENSE FEEDBACK**：Off / Reduced / Full，控制热扭曲与命中补光，分别 0 / 35% / 100%。不是关闭整个游戏所有屏幕/水材质效果；原 Bloom、Motion Blur 开关保持独立。

菜单延用项目已有的运行时增加设置行方式，适用于暂停与标题设置，不覆盖 Prefab 或场景。偏好键为 `DarkBrine.Settings.VfxQuality`、`CameraShake`、`ScreenEffects`；旧用户无这些键时使用 High / Full / Full。

## 实际验证

最终选定报告共 **132 项原生运行检查通过**，报告与截图在 `CombatVfxUpgradeReview/`，完整逐帧证据在 `.codex/vfx-quality/`。

- 沙盒战斗与第一岛光照各 18 项：真实 Sahur 攻击、棍蓄力与释放、双刀轻击/蓄力/冲刺/旋转、真实目标扣血、原 Bombardino 爆炸及 Cappuccino 尘土、池上限、深度/颜色缓冲归还、完整清理。两次各渲染记录 403 帧。
- 材质、枪口、落地与 Nailong 37 项：七种材质解析/发射/清理，原生枪口渲染及终止，显式木质落地，Nailong 实际地面碰撞、六滴数量与原回收行为。
- 设置与质量 33 项：真实菜单按钮、Apply 保存、返回取消、重新打开读取，三档采样/烟层/缓冲请求，切档清理，以及 Camera Shake Off 的零位移验证。已查看 GRAPHICS 与 GAMEPLAY 菜单的实际渲染截图。
- 武器回归 26 项：棍和双刀蓄力/取消/旋转/格挡，M4A1 开火与瞄准，真实子弹触发岩石/木/金属接触，枪口结束，投棍与返回。
- Unity 编译成功，最终记录没有运行或着色器错误。这里统计的是原生脚本回放检查，不冒充 NUnit 测试数量。

早期 `surfaces-first` 发现名称 `Vegetation` 未列入回退规则，已修复并通过最终回放。早期 `quality/feedback-menu.png` 在测试误关闭菜单后拍到空白；最终以 `quality-final` 的重新打开和可见截图为准。中间报告保留用于审计，不列入上述最终通过数。

## 性能实测与边界

同一固定效果负载，每档 60 帧预热、180 个有效样本，`BrineVFX.BoundedWorld` CPU Update P95：High **0.0837ms**，Medium **0.0767ms**，Low **0.0668ms**。该负载循环两个原池接触，不包括完整 Boss AI。

相同沙盒战斗回放前后共用 VFX 脚本 P95 为 0.4888ms / 0.4779ms；最终第一岛回放为 0.5826ms。不同场景不能直接作为性能提升对比。这些数据是编辑器中的脚本指标，录像包含相机渲染和读回开销，**不代表 GPU 时间或发布版 FPS**。没有为其他硬件作帧率保证，没有重新打包发布版。
