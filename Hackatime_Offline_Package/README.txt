Unity Hackatime — offline install

1. Extract this archive somewhere on your computer.
2. Open your Unity project.
3. Go to Window > Package Manager.
4. Click + (top-left) > Add package from disk...
5. Select: com.daniel-geo.unityhackatime/package.json
6. In Unity, open Tools > Hackatime and enter your API key.
